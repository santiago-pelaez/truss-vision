# Contributing to Truss-Vision

Truss-Vision is a Hacktoberfest prototype based on the MIT-licensed [statics-simulator](https://github.com/VictorKaraboychev/statics-simulator).

Before opening a pull request:

1. Keep the upstream MIT license and attribution intact.
2. Do not commit API keys, scanned course material, full exams, or local input archives.
3. Run `npm run build` from `frontend`.
4. Run `python -m pytest` from `backend` when the test dependencies are installed.
5. Describe whether your change affects the extracted scene contract or solver behavior.
