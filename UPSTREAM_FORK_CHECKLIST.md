# Upstream fork handoff

The local workspace contains the Truss-Vision implementation and migration reference. The final MLH submission must be hosted from an actual GitHub fork of the MIT-licensed upstream project:

<https://github.com/VictorKaraboychev/statics-simulator>

Complete this account-level step before submitting:

1. On GitHub, click **Fork** on the upstream repository and select the team owner's account.
2. Add the fork as the submission repository and keep the upstream repository visible in the fork banner.
3. Push this workspace to that fork. Do not push the ceremony PDF, statics input archives, private scans, or `.env` files.
4. Keep the upstream MIT license and the attribution in `THIRD_PARTY_NOTICES.md`.
5. Add all teammates as contributors and use the fork URL in the MLH form.

The code-level work is ready for that handoff; GitHub account ownership and fork creation cannot be completed from this local workspace without the team's authenticated GitHub session.
